# Android release guide

Branch: `android`. Companion to `docs/android-migration.md` and `docs/android-production-checklist.md`.

## Architecture (short)

```text
APK WebView (https://localhost)
  → http://127.0.0.1:8787 (Chaquopy + FastAPI)
  → MX HTTPS + HLS via http://127.0.0.1:<proxy_port>
```

Port/host SSOT: `frontend/src/lib/androidLocalApi.json` (Gradle `BuildConfig` + React `apiBase.ts`).

## Build commands

```powershell
cd frontend
npm run cap:sync

cd android
$env:JAVA_HOME = 'C:\Program Files\Microsoft\jdk-21.0.12.101-hotspot'  # example
.\gradlew.bat :app:lintDebug
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:assembleRelease
```

Artifacts:

- Debug: `frontend/android/app/build/outputs/apk/debug/app-debug.apk` (~47.7 MB)
- Release: `frontend/android/app/build/outputs/apk/release/app-release.apk` (~45.8 MB)

AAB is not generated by default. For Play:

```powershell
.\gradlew.bat :app:bundleRelease
```

## Signing

**Do not commit keystores or passwords.**

Play / production release — pass Gradle properties (or `~/.gradle/gradle.properties`):

```text
MX_RELEASE_STORE_FILE=C:/path/to/upload.keystore
MX_RELEASE_STORE_PASSWORD=...
MX_RELEASE_KEY_ALIAS=...
MX_RELEASE_KEY_PASSWORD=...
```

If unset, release builds fall back to the **Android debug keystore** for local sideload only. That is **not** valid for Play Store.

## Environment separation

| Mode | API base |
|------|----------|
| Web dev | Vite proxy / empty `VITE_API_BASE_URL` |
| Web prod | Set `VITE_API_BASE_URL` at build time if needed |
| Android (debug/release) | Always `http://127.0.0.1:8787` from `androidLocalApi.json` |

Leave `VITE_API_BASE_URL` empty for APK builds so loopback is not overridden.

## Device install

```powershell
adb install -r frontend/android/app/build/outputs/apk/release/app-release.apk
adb shell am start -n com.mxscraper.app/.MainActivity
adb logcat -s MxLocalApi:I Capacitor/Console:I
```

Release WebViews are non-debuggable (no Chrome CDP). Use debug APK for inspector-based QA.

## Known limitations

1. Downloads require `jniLibs/<abi>/libffmpeg.so` (see `docs/ffmpeg-android.md`). Until then: `ffmpeg: unavailable`.
2. Auth0 removed on this branch — stream/download public on loopback.
3. HLS proxy still buffers full responses (`stream=False`) — deferred streaming refactor.
4. Process death drops in-memory download jobs.

## Troubleshooting

| Symptom | Check |
|---------|--------|
| Infinite “Starting local API” | logcat `MxLocalApi`; Python/Chaquopy crash |
| Catalog empty | `/health` then `/api/search` via `adb forward tcp:18787 tcp:8787` |
| No video | Mixed content / proxy port; confirm `PROXY_BIND_HOST=127.0.0.1` |
| Download 503 | Missing FFmpeg binary |
| Back exits immediately | `__mxConsumeBack` / history; menus/FS consume back first |
